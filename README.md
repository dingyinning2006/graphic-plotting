
# 图形绘制与面积周长计算系统

一个使用C++和Qt实现的图形绘制与面积周长计算系统，支持创建圆形、矩形和三角形，计算它们的面积和周长。

## 功能特点

- 创建圆形、矩形和三角形
- 计算图形面积和周长
- 图形可视化显示
- 保存和加载图形数据
- 导入/导出CSV格式数据
- 按面积、周长、ID和类型排序
- 缩放和平移视图
- 编辑图形属性

## 环境要求

- Qt 5.12或更高版本
- C++17兼容的编译器

## 编译和运行

### 使用qmake编译

1. 打开终端，进入项目目录
2. 运行qmake生成Makefile：
   ```
   qmake GraphicPlotting.pro
   ```
3. 编译项目：
   ```
   make
   ```
4. 运行程序：
   ```
   ./GraphicPlotting
   ```

### 使用Qt Creator编译

1. 打开Qt Creator
2. 选择"文件" > "打开文件或项目"
3. 选择项目目录中的GraphicPlotting.pro文件
4. 构建并运行项目

## 项目结构

- `Shape.h/cpp` - 抽象基类Shape定义
- `Circle.h/cpp` - 圆形类实现
- `Rectangle.h/cpp` - 矩形类实现
- `Triangle.h/cpp` - 三角形类实现
- `ShapeManager.h/cpp` - 图形管理器，负责批量操作
- `MainWindow.h/cpp` - 主窗口界面
- `ShapeCanvas.h/cpp` - 图形画布组件
- `AddShapeDialog.h/cpp` - 添加图形对话框
- `ShapeExceptions.h` - 自定义异常类

## 使用说明

1. 添加图形：点击"添加图形"按钮，选择图形类型并设置参数
2. 选择图形：点击画布上的图形或表格中的行来选择图形
3. 编辑图形：选中图形后，在属性编辑器中修改属性
4. 删除图形：选中图形后，点击"删除图形"按钮
5. 缩放视图：使用鼠标滚轮或工具栏按钮进行缩放
6. 平移视图：按住鼠标左键拖动画布
7. 排序图形：使用菜单栏中的排序选项

## 技术特点

- 使用多态性管理不同类型的图形
- 使用STL容器管理图形对象
- 实现了异常处理机制
- 支持序列化和反序列化
- 使用Qt框架实现图形界面
